# 공식 스테이지 안내: 전수 후보 조사와 제공 범위

2026-10-25 기준 공개 목록에서 발견한 1,295개 후보 URL을 확인했다. 이름이 있는 공식 안내 1,067개 맵 / 4,976개 스테이지를 수집했다. 한국어 맵 또는 스테이지 이름이 확인된 맵은 1,000개, 그 외 원문 맵은 67개다. 이 기준은 한국판 출시 여부의 인증이 아니다. 기본 화면은 한국어 안내만 표시하며 필터를 해제하면 나머지 공식 원문도 볼 수 있다.

## 공식 출처

`https://ponosgames.com/information/appli/battlecats/stage/kr/<CODE>.html`의 실제 응답에서 이름, 필요 통솔력 또는 필요 아이템, 난이도, 보상, 출현 적 아이콘만 추출한다. 맵마다 원문 URL, 확인 시각, 원문 SHA-256을 저장한다. HTML·게임 스크립트 전체는 배포하지 않는다.

- 적 목록은 `stageN_enemy_list_1`만 읽으며 물음표 목록은 제외한다. 아이콘 중복은 종류로 묶고 마릿수로 해석하지 않는다.
- 적 이름·배율·출현 마릿수·시각은 원문 미기재이므로 null이다. 이미지 파일 번호를 적 도감 ID로 매칭하지 않는다.
- 아이콘은 원문이 가리키는 PONOS URL에서 직접 받은 원본 PNG다. 729개 아이콘 참조 중 723개 원본을 확인했고, 6개는 HTTP 403으로 이미지 미확인 상태다. 미확인 이미지를 커뮤니티 보관본으로 대체하지 않는다.
- 327개 스테이지는 공식 페이지에서 개별 이름이 비어 있다. 원본 값은 빈 문자열로 보존하고 화면에 '공식 이름 미기재'라고 표시한다. 다른 사이트의 번역으로 채우지 않는다.
- 통솔력 대신 고양이 드링크가 필요한 안내는 해당 소비 아이템과 수량을 원문대로 표시한다. 이를 통솔력으로 바꾸지 않는다.
- 숫자는 공식 안내의 기본 표시값이다. 성급·할인·계정별 입장 조건·현재 개방 상태를 모두 확인했다고 주장하지 않는다.
- 개최일은 공식 KR 이벤트 공지의 맵 이름이 정확히 일치할 때만 연결한다. 맵 개최 기간을 개별 스테이지 순차 개방일로 간주하지 않는다.

## 확인하지 못한 정보

228개 후보는 상세 안내로 채택하지 않았다. 183개는 HTTP 403, 43개는 공식 맵 이름 미제공, 2개는 공식 더미 표시다. HTTP 403만으로 해당 스테이지가 게임에 없거나 종료됐다고 판단하지 않는다.

세계편·미래편·우주편·마계편에 해당하는 메인 계열, EX, 도장/랭킹 도장, 지하 미궁, 검정 및 일부 신규 계열은 이 공식 상세 안내 경로에서 확인하지 못했다. 이 부분을 위키 수치로 채우지 않는다. 신규 계열 P의 접두어 연결은 미확정 후보이므로 해당 후보 실패로 그 계열의 공식 정보가 전혀 없다고 단정하지 않는다. 공식 도움말은 메인 콘텐츠에 대한 일반 설명을 제공하지만 각 스테이지의 상세 출현 적 전체를 대신하지 못한다.

저장소의 `public/data/stage-audit.json`과 사이트의 '공식 자료 수집 현황'에서 계열별 후보·확인 맵·한국어 맵·스테이지 수와 경로별 미확인 사유를 공개한다. 후보 목록도 알려진 공개 목록에 기반하므로 미발견·삭제·신규 스테이지까지 빠짐없다는 증명은 아니다.

## 갱신과 배포

```sh
python3 -m pip install -r requirements-stages.txt
npm run stages
npm run check
```

수집기는 연결 풀 4개로 제한해 공식 페이지를 확인한다. URL·해시·확인 시각이 일치하는 24시간 미만의 로컬 HTML 캐시는 재사용한다. `python3 scripts/collect-stages.py --refresh`로 재확인할 수 있다. 실패한 기존 맵은 원래 확인 시각과 재확인 실패 표시를 유지한다. HTTP 429를 만나면 수집을 중단한다. 이미지 다운로드 실패는 '이미지 미확인'으로 기록하며 다른 출처로 대체하지 않는다.

검색 색인은 약 581KB이고 상세 13개 계열 파일은 선택 시에만 불러온다. 원본 적 참조는 공통 아이콘 목록을 통해 복원한다. 원본 데이터 전체 약 8.7MB를 첫 화면에서 받지 않는다. 검증기는 모든 계열 상세를 복원한 결과가 전체 공식 스냅샷과 정확히 일치하는지 비교한다.

`artwork/official-stage-data.json.gz`, `official-stage-icons.tar.gz`와 SHA-256 목록으로 전체 자료와 원본 PNG를 보존한다. `npm run assets`는 체크섬을 확인하고 원본 바이트를 복원한다. Pages에는 복원된 JSON·PNG가 포함된다. 스테이지 카탈로그는 저장소 스냅샷이며 공식 이벤트 일정은 기존 6시간 주기 workflow에서 갱신된다.
