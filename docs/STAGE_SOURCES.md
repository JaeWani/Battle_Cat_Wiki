# 스테이지 안내 출처와 제공 범위

스테이지 탭은 PONOS의 한국판 게임 내 안내 HTML을 직접 읽어 제공한다. 캐릭터 도감의 커뮤니티 TSV와 이미지 보관본을 스테이지 출현 정보에 사용하지 않는다.

- 공식 원문: `https://ponosgames.com/information/appli/battlecats/stage/kr/<CODE>.html`
- 확인된 맵마다 원문 URL과 `verifiedAt`을 저장한다.
- 통솔력, 난이도, 보상은 HTML에 표시된 기본값이다. 성급, 할인, 진행도별 입장 조건까지 확인했다고 주장하지 않는다.
- 적은 원문의 `stageN_enemy_list_1`에 있는 공식 아이콘 목록만 읽는다. 미공개 상태의 물음표 목록은 제외한다. 중복 아이콘은 적 종류로 묶으며 마릿수로 해석하지 않는다.
- 원문에 없는 적 이름, 배율, 출현 마릿수·시각은 null이다. 파일명의 번호는 도감 ID와 동일하다고 보장하지 않는다.
- 아이콘은 같은 PONOS 서버에서 직접 받은 원본 PNG다. 가공하지 않으며 URL과 SHA-256을 저장한다.
- 개최일은 수집된 KR 공식 이벤트 공지와 맵 이름이 정확하게 일치할 때만 연결한다. 공백과 말미의 '개최!'만 보수적으로 정규화한다. 부분 일치·유사도 검색은 사용하지 않는다. 맵 개최일을 개별 스테이지 순차 개방일로 간주하지 않는다.
- 일정이 확인되지 않으면 상시/종료/미개최로 추정하지 않는다. 공식 게임 캘린더는 현재 수집 경로에서 403으로 확인되지 않아 사용하지 않았다.

## 분류 명칭 참고

사용자의 요청에 따라 나무위키의 '냥코 대전쟁/스테이지', '냥코 대전쟁/스페셜 스테이지' 문서 구분을 참고해 탐색 메뉴를 일부 재구성했다. 분류는 PONOS의 공식 분류 인증을 의미하지 않는다.

- 원문: https://namu.wiki/w/냥코%20대전쟁/스테이지
- 원문: https://namu.wiki/w/냥코%20대전쟁/스페셜%20스테이지
- 확인일: 2026-10-25. 원문 직접 열람은 검색 도구에서 실패했으며 검색에 색인된 동일 문서 보관본의 제목 구분을 확인했다.
- 확인한 보관본: https://seore.org/raw/문서:냥코%20대전쟁/스테이지?rev=9 및 https://seore.org/raw/냥코%20대전쟁/스페셜%20스테이지
- 메인, 레전드 스토리, 신 레전드 스토리, 발굴, 콜라보, 스페셜, 챌린지 배틀, 냥코 도장 구분을 참고했다. 스페셜은 아이템·요일, 개다래, 사이클론, 광란, 강림·대강림, 기타 이벤트로 단순화했다.
- 문서 본문·공략·표·수치·이미지는 가져오지 않는다. 분류 명칭 외 실제 데이터는 PONOS 출처만 이용한다. 최신 문서의 전체 목차를 그대로 재현한다고 주장하지 않는다.

## 갱신

`config/official-stage-sources.json`은 수집할 공식 페이지 목록이다. `npm run stages`로 다시 확인하고 `npm run check`로 출처·이미지 해시·미기재 항목을 검증한다. 일부 페이지가 실패하면 기존 맵 스냅샷을 원래 확인 시각과 함께 보존하고 `sourceFailures`에 남긴다. 모든 수집이 실패하거나 이미지가 검증되지 않으면 기존 JSON을 덮어쓰지 않는다. 이미 받은 아이콘은 저장된 출처와 해시가 일치할 때만 재사용한다.

스테이지 카탈로그는 저장소 스냅샷이다. 이벤트 공지는 기존 6시간 주기 Pages workflow에서 갱신되므로 스테이지 탭의 연결 일정에도 반영된다. 공식 자료 미확인 분류는 0개와 빈 상태 설명을 표시한다. 전체 스테이지 목록을 대체하지 않는다.
