- 390px 모바일 프레임에서 레이아웃과 수평 넘침 없음 확인.

- 아군 체력 25,500, 직접 공격 85,000 + 3,400 + 5,100.
- 적 체력 299,997, 직접 공격 6,750, 인식 사거리 모두 200.
