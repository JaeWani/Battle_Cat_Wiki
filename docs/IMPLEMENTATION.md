# 냥코 도감 · 전투 계산기

## 목표
- 아군 도감 / 적군 도감: 한국어 이름, 진화 형태, 기본 능력치, 특수능력, 출처.
- 아군 선택 + 총 레벨, 적 선택 + 배율(%)로 직접 공격 기준 처치 타수 / 피격 사망 타수 / 사거리 차이 계산.
- 이미지와 이름을 함께 표시하는 선택창, 적 속성별 필터, 이름/ID 검색, 모바일 대응.
- 원본 게임 아트의 커뮤니티 보관본만 사용. 생성 이미지, 팬아트, 외부 아이콘 라이브러리 미사용. 이미지 출처 및 체크섬 기록.
- 정적 파일로 구성하고 GitHub Pages에 배포.

## 데이터 및 계산
- battlecatsinfo/battlecatsinfo.github.io 의 TSV 데이터와 레벨 성장표를 변환.
- 원본 수치 및 능력 정의 출처와 MIT 고지를 보존. PONOS 및 콜라보 권리는 해당 권리자에 귀속되며 공식 서비스/제휴를 주장하지 않음.
- 일반 직접 공격을 기본으로, 상시 속성 피해/방어 보정, 메탈, 공격 대상 제한, 연속공격을 처리.
- 확률 효과는 미발동/발동 조건을 명시. 파동/열파, 행동 방해, 부활, 실전 이동/넉백/명중률은 전투 시뮬레이션에 포함하지 않음.
- 배리어/악마 실드는 경고와 적용 범위를 명시.
- 레벨, 배율, 연속공격, 메탈, 피해 보정, 예외에 대한 자동 테스트와 화면 검증.

## 배포
- 공개 저장소의 main 브랜치에 소스·정적 데이터·원본 이미지·검증·문서 기록.
- GitHub Pages 배포 워크플로를 추가하고 실행 결과 확인.
