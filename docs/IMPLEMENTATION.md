# 냥코 도감 · 전투 계산기

## 목표
- 아군 도감 / 적군 도감: 한국어 이름, 진화 형태, 기본 능력치, 특수능력, 출처.
- 아군 선택 + 총 레벨, 적 선택 + 배율(%)로 직접 공격 기준 처치 타수 / 피격 사망 타수 / 사거리 차이 계산.
- 이미지와 이름을 함께 표시하는 선택창, 적 속성별 필터, 이름/ID 검색, 모바일 대응.
- 원본 게임 아트의 커뮤니티 보관본만 사용. 생성 이미지, 팬아트, 외부 아이콘 라이브러리 미사용. 이미지 출처 및 체크섬 기록.
- 정적 파일로 구성하고 GitHub Pages에 배포.

## 데이터 및 계산
- battlecatsinfo/battlecatsinfo.github.io 의 TSV 데이터와 레벨 성장표를 변환.
- 원본 수치 및 능력 정의 출처와 MIT 고지를 보존. PONOS 및 콜라보 권리는 해당 권리자에 귀속되며 공식 서비스/제휴를 주장하지 않음.
- 일반 직접 공격을 기본으로, 상시 속성 피해/방어 보정, 메탈, 공격 대상 제한, 연속공격을 처리.
- 확률 효과는 미발동/발동 조건을 명시. 파동/열파, 행동 방해, 부활, 실전 이동/넉백/명중률은 전투 시뮬레이션에 포함하지 않음.
- 배리어/악마 실드는 경고와 적용 범위를 명시.
- 레벨, 배율, 연속공격, 메탈, 피해 보정, 예외에 대한 자동 테스트와 화면 검증.

## 배포
- 공개 저장소의 main 브랜치에 소스·정적 데이터·원본 이미지·검증·문서 기록.
- GitHub Pages 배포 워크플로를 추가하고 실행 결과 확인.

## 스테이지 탭

`stage-guide.mjs`는 공식 `stages.json`과 한국판 `events.json`만 사용한다. 캐릭터 도감 데이터나 이미지 아카이브를 적 매칭에 사용하지 않는다. 나무위키를 참고한 분류 명칭과 PONOS의 게임 사실 출처를 화면에서 분리해 표시한다. `stages.mjs`가 검색·분류·일정의 정확한 이름 연결을 담당하며, UI 모듈은 기존 홈/계산기와 별도로 초기화한다. 수집 및 제공 범위는 `STAGE_SOURCES.md`에 기록했다.

## 전체 후보 조사와 카탈로그 확장

공식 경로 후보 1,295개를 확인해 이름이 있는 안내 1,067개 맵/4,976개 스테이지를 수집했다. 경로 후보 ID·접두어만 공개 개발 자료에서 발견하고 실제 표시 정보는 PONOS 응답에서 추출한다. 미확인 228개 후보, 한국어 안내 여부, 원문 이름 미기재와 이미지 미확인 상태를 구분한다.

`build-stage-catalog.py`는 약 581KB 검색 색인과 원본 데이터를 압축한 13개 상세 계열을 생성한다. 상세는 선택할 때만 불러오고 36개 맵씩 페이지를 나눠 표시한다. 비동기 요청이 늦게 완료돼도 현재 선택한 맵과 일치할 때만 화면을 갱신한다. `hydrateStageGroup`는 공통 원본 이미지 참조를 복원하며 누락 참조는 오류로 처리한다. 전수 검증에서 각 상세 계열을 복원한 결과와 전체 스냅샷이 일치하는지 비교한다.

공식 원본 PNG 723개와 전체 스냅샷은 체크섬이 있는 압축 파일로 보관하고 Pages 빌드에서 복원한다. 캔버스 변환·리사이즈·팬아트 대체를 수행하지 않는다. 수집기는 선택적 수집 의존성 `aiohttp`를 이용하며 사이트 실행과 CI 검증에는 추가 Python 패키지 설치가 필요하지 않다.
