# 목표 육성과 일정 연결

내 정보 → **육성 목표**에서 캐릭터, 현재 진화 완료 단계, 목표 기본 레벨·형태를 설정합니다. 같은 캐릭터의 목표를 저장하면 변경됩니다. 최대 24개이며, 여러 목표의 재료를 합산한 뒤 보유량을 한 번만 적용합니다. 보유 재료는 직접 입력합니다. 목표 제거는 재료를 소비하지 않습니다.

계정의 보유 캐릭터가 있으면 저장된 기본 레벨과 선택 형태를 참고합니다. 플러스 레벨은 XP 비용에 포함하지 않습니다. 선택 형태가 이미 해금한 최종 진화와 다를 수 있으므로 현재 진화 완료 단계를 확인·수정할 수 있습니다. 본능 기록과 게임 프로필은 읽기만 하며 변경하지 않습니다.

계획과 보유 재료는 `noc-growth-v1:<account-id>` 또는 `noc-growth-v1:guest` 키로 **이 브라우저에만** 저장합니다. 로그인 계정과 비로그인 계획을 자동 합치지 않습니다. 기기 간 동기화·서버 저장은 제공하지 않습니다. 계정 전환 시 다른 계정 계획을 표시하지 않으며, 브라우저 저장 실패·읽기 실패를 안내합니다. 사이트 데이터를 삭제하면 계획도 지워집니다.

## 데이터와 계산 범위

- `scripts/import-growth-data.py`는 기존 도감과 같은 MIT 수치 자료 저장소 `battlecatsinfo/battlecatsinfo.github.io`의 `4baf8c1b468230a14f9350d646f60d888e3fe75d`에 고정합니다. 입력 파일 4개의 Git blob SHA를 검사하고 SHA-256도 결과에 기록합니다.
- 입력: `data/cat.tsv`, `units_scheme.json`, `reward.tsv`, `titem.tsv`. 원본 URL은 `https://raw.githubusercontent.com/battlecatsinfo/battlecatsinfo.github.io/<commit>/data/<filename>`입니다.
- 진화 재료는 `evol_require`·`evol4_require`의 수량/보상 ID를 해석하며 0번 비용은 XP입니다. 재료 ID는 reward.tsv와 titem.tsv의 일치하는 원문 이름을 통해 한국어로 연결합니다. 이름이 모호하면 원문을 유지합니다.
- 882종 중 재료 레시피가 있는 286종을 포함합니다. 레시피가 없는 진화는 무료라고 간주하지 않고 미확인 조건으로 표시합니다.
- 기본 레벨 1→50 구간의 XP는 원본 `template/js/unit.mjs`의 `getXpCost(level)` 방식(구간 배수 × 해당 레벨 곡선)을 따릅니다. XP 곡선이 없는 경우 미확인입니다. 51 이상은 추정하지 않습니다.
- 캣츠아이, 본능 비용, 진화 필요 레벨, 유저랭크/클리어/레벨 해방 조건은 미산정입니다. 해당 비용·조건이 빠진 계획을 완전한 준비 완료로 표시하지 않습니다. JP/TW 수치 자료이므로 실제 한국판 비용도 확인해야 합니다.
- 획득처 1,181개는 이미 저장된 **PONOS 한국판 공식 스테이지 보상 문구**에 해당 재료 이름이 있는 경우만 연결합니다. XP는 명시적인 XP 보상만 포함합니다. 기본 클리어 경험치 전체를 모델링하지 않습니다. 원문 보상 설명과 확인 날짜를 표시하고, 1회성 보상도 구분 없이 반복 파밍으로 취급하지 않습니다.
- 확률, 평균 반복 횟수, 최고의 통솔력 효율, 개인 입장 가능 여부를 계산하거나 보장하지 않습니다. 후보는 일정 상태, 같은 상태에서는 표시 통솔력으로 정렬하고 최대 5개를 표시합니다.

## 일정 상태

확인된 명시적 맵→공지 연결만 사용합니다. 초기 검토 목록은 `S250` 종말의 배틀 그라운드(공지 14482), `V000` 풍운 냥코탑(공지 14348)입니다. 공지 ID는 검토 이력이고, 같은 정확한 제목의 새 한국판 이벤트 공지도 사용할 수 있습니다. 다른 맵이나 비슷한 단어가 있는 공지로 개방 기간을 추측하지 않습니다.

연결된 공식 공지의 기간 내/예정/종료, 반복 개최일, 오늘이 아닌 반복 개최일, 개방 미확인을 구분합니다. 반복 개최일은 현재 열려 있음을 뜻하지 않으며 정확한 시간은 원문 확인이 필요합니다. 36시간 초과 스냅샷, 수집 오류, 잘못된 지역, 비정상적으로 미래인 수집 시각은 갱신 지연으로 처리합니다. 잘못된 기간은 미확인으로 처리합니다. 공식 공지 부재는 인게임 이벤트 부재를 뜻하지 않습니다.

## 재생성·검증

```sh
python3 scripts/import-growth-data.py /path/to/pinned-data-directory
npm run assets
npm test
npm run check
node scripts/review-interface.mjs
```

생성 결과는 `artwork/growth.json.gz`에 결정적으로 압축 보관하고 `npm run assets`에서 `public/data/growth.json`으로 복원합니다. CI가 공식 공지 일정을 갱신하므로 수치 자료의 생성 시각을 현재 일정의 근거로 사용하지 않습니다.

Node 테스트는 원본 핀과 진화 레시피, 공식 획득처 문구, 여러 목표의 재료 중복 배분, 계정 진행 반영, 완료 목표, 미확인 비용, 잘못된 입력, 기간 경계·종료·예정·갱신 지연·수집 오류·반복 개최일과 키워드 오연결 방지를 검사합니다. 실제 Chrome에서는 모바일/데스크톱의 프로필 탭, 목표·재료 저장, 새로고침 복원, 목표 제거, 공식 링크, 계정별 격리와 저장 실패 안내를 검사합니다. 계정 전환 검사는 격리된 UI 어댑터이며 실계정 로그인 테스트로 주장하지 않습니다.
