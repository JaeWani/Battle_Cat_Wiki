NOC SAVE_DATA 가져오기 검증용 합성 데이터

실제 게임 계정의 세이브가 아닙니다. 게임 복원/인계용으로 사용하지 마세요.
1. ZIP을 압축 해제합니다.
2. 냥작사 > 내 정보 > 데이터 가져오기에서 SAVE_DATA 파일을 선택합니다.
3. 아래 결과와 비교합니다. 계정에 저장하면 기존 게임 정보 스냅샷이 교체됩니다.

한국판 / 버전 15.5.0
보유 캐릭터: 2종
고양이 빌더: 기본 Lv.20, +15, 2진화
각성의 고양이 무트: 기본 Lv.30, +0, 3진화
최고 총 레벨: 35
세계편 1장: 48/48 클리어, 최고급 보물 48/48
그 외 8개 메인 챕터: 클리어 0, 최고급 보물 0

파일은 사이트 파서가 사용하는 앞부분과 검사값을 갖춘 테스트 픽스처이며, 게임 전체 세이브 구조는 포함하지 않습니다.
expected.json은 사이트 파서가 반환해야 하는 값입니다.
