# 냥코 연구소 · Battle Cat Wiki

한국판 이벤트 일정을 첫 화면으로 제공하는 냥코 대전쟁 팬 사이트입니다. 아군·적군 도감과 직접 공격 전투 계산기도 제공합니다. 위키 문서나 화면을 미러링하지 않고, 공개 수치 데이터 파일을 변환해 독립적인 UI와 계산 엔진을 제공합니다.

## 구현 기능

- **이벤트 일정 홈**: 첫 방문 기본 화면. 공식 한국판 공지에서 기간을 확인한 이벤트·뽑기, 날짜 선택, 주간 이동, 종류 필터·검색, 진행 상태·종료 임박·갱신 시각.
- **스테이지 정보**: 알려진 후보 1,295개 공식 경로를 조사해 1,067개 맵 / 4,976개 스테이지 확인. 한국어 안내 맵 1,000개, 그 외 원문 67개를 구분. 공식 원본 적 아이콘 723종 및 미확인 이미지 6종을 구분하고, 계열별 수집 현황·누락 사유를 공개합니다. 전체 게임 목록 또는 현재 한국판 개방 여부를 보장하지 않습니다.
- **첫 화면에서 계산기 분리**: 메뉴 및 빠른 이동으로 접근. 기존 `#calculator` 공유 링크는 계산기를 바로 엽니다.
- **공식 공지 수집**: 계정/인증 없이 공개된 한국판 공지의 짧은 제목·명시된 개최 기간과 원본 배너만 수집. 전체 문서 복제 및 미공개 일정 추정 미사용.
- **자동 갱신**: Pages workflow가 6시간마다 수집·검증 후 배포. GitHub Actions 실행 시각은 지연될 수 있습니다. 수집 실패 시 저장된 스냅샷을 유지하고, 36시간 이상 오래되면 홈페이지에 갱신 지연 표시.

- **아군 도감**: 882종 / 2,177개 진화 형태. 희귀도·대상 속성 필터, 이름/ID 검색, 형태 전환, 능력치·특수능력 상세 정보.
- **적군 도감**: 792종. 이미지와 전체 이름을 함께 표시하는 카드, 속성 필터, 한국어·일본어·영어 검색.
- **전투 계산**: 아군 총 레벨, 적 배율(%), 세계편 보물, 속성 보물, 아군 크리티컬·혼신의 일격 발동 조건.
- **결과**: 본체 처치 타격 수, 연속공격 동작 횟수, 아군 사망 피격 수와 생존 가능한 피격 수, 인식 사거리 차이, 체력·공격력·DPS 비교.
- 선택한 조건을 브라우저에 저장하고 URL로 공유. 모바일 대응. 외부 서버·로그인·방문자 추적 없음.
- 캐릭터 원본 아트 보관본 2,969개를 압축 묶음으로 보관하고 배포 시 원본 바이트 그대로 복원. 파일별 SHA-256 기록. 생성 이미지·팬아트·외부 아이콘 패키지 미사용.

## 실행과 검증

추가 패키지 설치가 필요하지 않습니다. Node.js 22 이상에서:

```sh
npm run assets
npm test
npm run check
```

`artwork/`에는 변형하지 않은 원본 PNG의 분할 압축 파일이 있습니다. `npm run assets`는 압축 파일의 해시를 확인한 뒤 `public/assets/`에 복원합니다.

로컬 실행은 `public/`을 정적 HTTP 서버로 제공하세요. Python이 있다면:

```sh
python -m http.server 8080 --directory public
```

`http://localhost:8080/`에 접속합니다. 파일을 `file://`로 직접 열면 JSON fetch가 차단될 수 있습니다.

## 이벤트 갱신

```sh
npm run events
npm run check
```

결과는 `public/data/events.json`, 배너는 `public/event-assets/`에 저장됩니다. 수집 출처는 `https://nyanko-announcement.ponosgames.com/v1/notices`의 `countryCode=ko` 한국판 공지이며, 수집용 clientVersion 기본값은 `150500`입니다. 공지 노출 조건은 이 버전을 기준으로 하므로 필요하면 `BATTLE_CATS_KR_NOTICE_VERSION` 환경변수로 갱신하세요.

- 게시일을 개최일로 대체하지 않습니다. 날짜와 시각이 명시된 대표 개최 기간만 캘린더에 넣습니다.
- 반복 개최일만 명시된 일정은 시간 미확인 상태로 표시하고, '진행 중' 수에 포함하지 않습니다. 동일 반복 공지는 최신 글 하나로 정리합니다.
- 기간 미확인 공지는 별도의 공식 소식 영역에 표시합니다. 모든 인게임 이벤트나 미발표 미래 일정을 수집했다고 주장하지 않습니다.
- 공식 공지의 종료 시각 10:59는 해당 분까지 표시되도록 내부 종료 경계를 11:00으로 저장합니다. 화면은 공지 원문의 10:59를 표시합니다.
- 본문 전체는 저장하지 않습니다. 배너는 PONOS 원본을 가공 없이 복사하고 출처 URL·SHA-256을 기록합니다. 만료되는 이미지 URL의 서명 매개변수는 저장하지 않습니다.
- 자동 갱신 결과는 배포 산출물에 포함됩니다. 매번 저장소에 자동 커밋하거나 사용자 토큰을 저장하지 않습니다.

## 스테이지 자료 갱신

```sh
python3 -m pip install -r requirements-stages.txt
npm run stages
npm run check
```

`config/official-stage-sources.json`에 있는 PONOS 한국판 페이지를 읽습니다. `public/data/stages.json`에 맵별 원문·확인 시각과 아이콘 해시를 저장하고, 검색 색인은 `public/data/stage-index.json`, 상세는 `public/data/stage-groups/`에서 계열별로 나눠 불러옵니다. 전체 스냅샷과 원본 PNG는 `artwork/official-stage-*` 압축 파일로 보관하며 `npm run assets`로 바이트 그대로 복원합니다. 스테이지 카탈로그는 저장소 스냅샷이며 일정 공지는 기존 6시간 주기 배포에서 갱신됩니다. 전체 게임 스테이지·성급·계정별 입장 조건까지 포함하지 않습니다. [출처와 제공 범위](docs/STAGE_SOURCES.md)를 참고하세요.

## 캐릭터 데이터 갱신

```sh
git clone https://github.com/battlecatsinfo/battlecatsinfo.github.io.git /tmp/battlecats-data
git clone https://github.com/battlecatsinfo/img.git /tmp/battlecats-img
python scripts/import-data.py /tmp/battlecats-data /tmp/battlecats-img
npm test
npm run check
```

데이터 갱신 후 이미지를 다시 압축하려면 `python scripts/pack-artwork.py`를 실행하세요.

수치와 이미지의 원본 커밋은 `public/data/meta.json`, 이미지 경로·해시는 `public/data/images-manifest.json`에 기록됩니다. 이미지 저장소는 애니메이션 등 큰 파일도 포함하므로 복제 용량에 주의하세요. 변환 스크립트는 필요한 썸네일만 복사합니다.

**번역표의 행 번호를 캐릭터 ID로 사용하지 않습니다.** 특히 적군 번역표는 수치표와 행 구성이 다릅니다. 일본어 원본 이름을 정규화해 일치시키고, 불일치/중복 번역을 임의 추정하지 않습니다. 번역이 없는 항목은 원본 이름을 표시합니다.

## 계산 범위

- 캐릭터별 성장표와 단계별 반올림/내림을 적용합니다. 세계편 보물은 최대 ×2.5 또는 없음 ×1을 선택합니다.
- 적 배율은 최종 실효 배율이며 체력과 공격력에 함께 적용됩니다. 에이리언 보물에 따른 추가 배율은 별도 적용하지 않습니다.
- 직접 공격이 모두 명중한다고 가정합니다. 연속공격은 각 타격을 순서대로 누적하므로 `체력 ÷ 1회 공격력 합계`만으로 타수를 계산하지 않습니다.
- 상시 속성 공격·방어 보정, 메탈 1 피해, 공격 대상 한정, 특효를 반영합니다.
- 기본 모드에서는 100% 미만의 크리티컬·혼신의 일격이 미발동입니다. 발동 모드는 아군 해당 효과가 매번 발동한 조건이며 평균 타수가 아닙니다. 100% 효과는 기본 모드에도 반영합니다.
- **배리어·악마 실드는 제거한 본체 기준**, 좀비는 최초 체력 0 기준입니다. 해당 적 선택 시 결과에 경고를 표시합니다.
- 본능·초본능·본능옥·냥콤보, 공격력 상승, 살아남는다, 파동·열파·폭파·독·행동 방해·공격 무효·메탈 킬러 등은 미적용입니다. 적용 범위는 화면에 표시됩니다.
- 사거리 차이는 인식 사거리 기준이며, 전투 승패나 실제 명중을 판정하지 않습니다. 원거리/전방위의 타격 범위는 상세 도감에 표시합니다.

## GitHub Pages 배포

`.github/workflows/pages.yml`이 main 푸시 시 테스트 → 데이터 검증 → 정적 파일 업로드 → Pages 배포를 실행합니다. 최초 1회 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택해야 합니다. 이후 main 커밋마다 자동 배포됩니다. 최초 설정 전 실행은 Pages 설정 단계에서 실패할 수 있으며, 설정 후 Actions에서 워크플로를 다시 실행하면 됩니다.

GitHub의 기본 `GITHUB_TOKEN`만으로 Pages 최초 활성화를 할 수 없으므로, 임의로 권한을 확대하거나 외부 토큰을 저장하지 않습니다. 저장소 관리자 웹 설정이 필요합니다.
